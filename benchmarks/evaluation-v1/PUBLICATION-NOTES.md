# Evaluation file identities

Historical implementation references in this presentation use opaque `snapshot-NN`
labels. These labels are not Git commits and are not build inputs. Source bundles,
file manifests and binary checksums identify the corresponding implementations.

The evaluation inputs and quantitative observations retain their recorded values.
Annotation and execution descriptions use product-facing technical language.
Administrative records are excluded. File checksums in the lineage describe the
public files; original digests identify the earlier byte streams separately.
Changes to presentation metadata do not represent a new evaluation execution.

The tasks, vectors and relevance labels are fixed evaluation inputs. Their results
apply to the recorded datasets and settings; evaluate relevance on your own data.
